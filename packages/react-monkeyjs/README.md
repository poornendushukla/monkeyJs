# React-MonkeyJS

React-MonkeyJS is a React library that integrates seamlessly with the MonkeyTS framework, enabling developers to build interactive and reusable UI components in React applications. It leverages the power of MonkeyTS while providing a React-friendly API.

## Features

- React bindings for MonkeyTS components.
- Easy-to-use and intuitive API.
- Fully typed with TypeScript for enhanced developer experience.

## Installation

```bash
npm install react-monkeyjs
```

or with pnpm:

```bash
pnpm add react-monkeyjs
```
